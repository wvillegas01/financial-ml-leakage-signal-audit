# Reproducibility Package Manifest

This local package supports the manuscript "Auditing Information Leakage and Predictive Signal in Financial Machine Learning: A Controlled Study."

Prepared on: 2026-09-21

## Included Components

- Data generator:
  - `Auditoria/02_Descarga_Datos/`

- Preprocessing scripts and outputs:
  - `Auditoria/04_Preprocessing/`

- Model-training scripts and outputs:
  - `Auditoria/05_Modelado/`

- Evaluation scripts and outputs:
  - `Auditoria/06_Evaluacion/`
  - `Auditoria/06_Evaluación/`

- Analysis scripts and derived outputs:
  - `Auditoria/07_Analisis/`
  - `Auditoria/07_Análisis_Resultados/`

- Manuscript-related reproducible code and outputs:
  - `Auditoria/08_Paper/`
  - `Auditoria/08_Paper_Manuscrito/`

- Reproducible code folder:
  - `Auditoria/09_Código_Reproducible/`

- Controlled signal-injection validation:
  - `Auditoria/09_Validacion_Senal/`

- Robustness checks, including neural multiseed summaries, moving-block bootstrap diagnostics, and ensemble weight sensitivity:
